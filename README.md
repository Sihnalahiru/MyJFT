# Irodori Japanese Learning Web Application (彩り日本語)

Comprehensive educational web application built for the JFT-Basic and Irodori Japanese Language curriculum (Starter A1, Elementary 1 A2.1, and Elementary 2 A2.2).

## Features
- **Full Quiz System:** 644 Interactive questions across 54 lessons with audio playback, realia image zooming, and Sinhala explanations.
- **Vocabulary Bank:** Comprehensive word lists with Furigana, Romaji, English, and Sinhala translations.
- **Grammar Guide:** Detailed grammar explanations categorized by proficiency batches.
- **Kanji Explorer:** 400 Essential Kanji characters with On/Kun readings and stroke information.
